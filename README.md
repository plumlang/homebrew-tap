# Plumlang Homebrew tap

[Homebrew](https://brew.sh) formulae for [Plumlang](https://plum.elixpo.com),
a small, fast, memory-safe programming language.

```sh
brew install plumlang/tap/plum
plum version
```

The formula installs the release binaries published on
[plumlang/plumlang](https://github.com/plumlang/plumlang/releases): a universal
binary on macOS, and static binaries on Linux (x86_64, arm64).

## How it is updated

`Formula/plum.rb` is generated by the release workflow of
[plumlang/plumlang](https://github.com/plumlang/plumlang/blob/main/docs/releasing.md)
from `packaging/homebrew/plum.rb.in`, with the checksums of each release.
Do not edit it here: change the template in plumlang/plumlang.

Issues with the formula go to
[plumlang/plumlang](https://github.com/plumlang/plumlang/issues).
